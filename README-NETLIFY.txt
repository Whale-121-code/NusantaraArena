NUSANTARA ARENA — NETLIFY DEPLOY (VISUAL OVERHAUL v2)

1. Extract this ZIP.
2. Open https://app.netlify.com/drop
3. Drag the extracted folder whose top level contains index.html, netlify.toml, css/, js/, and assets/.
4. Wait for the deploy to finish and open the new Deploy Preview / site URL.
5. If updating an existing site: open Deploys > deploy manually, then drag the same extracted folder. Do not upload the ZIP file itself.

This build includes a noticeable visual refresh to the main menu, hero selection panels, and in-match HUD. It also forces HTML/CSS/JS revalidation to prevent an older stylesheet from being shown after redeploy. This is a static browser game; it does not include online multiplayer servers.


UPDATE V3 GAMEPLAY:
- 9 playable hero roster (3 additional legends).
- 23 shop items.
- Four named map landmarks with distinct terrain decoration.
- Shorter tower attack ranges.
- Towers lock onto the first enemy unit entering range and keep that target until it leaves/dies.
- Easy difficulty: towers only target minions, never heroes.
